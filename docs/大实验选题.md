### 1. 基于 Clang Static Analyzer (CSA) 的编译相关分析

**目标**：理解编译前端/中端中的静态分析，掌握 CSA 在漏洞检测中的作用。

**核心任务**：

- 安装配置 Clang + CSA（使用 scan-build）。
- 对 3-5 个含漏洞的 C 代码样本（缓冲区溢出、空指针、整数溢出等）运行 CSA，生成漏洞报告。
- 简单修改编译命令（添加 Checker 或分析选项），对比不同优化级别（-O0 vs -O2）下的检测效果。
- 网安结合：分析检测到的漏洞如何在供应链或运行时造成危害，尝试构造 1-2 个简单绕过 CSA 的案例。

**评估与输出**：

- 成功运行 CSA 并正确报告至少 4 类漏洞。
- 报告重点：CSA 在编译流程中的位置（AST/CFG/符号执行）、检测原理、局限性。

### 2. 基于 Rust 到 LLVM IR 编译流的相关问题分析

**目标**：理解 Rust 编译流水线，分析内存安全在 IR 层面的体现与问题。

**核心任务**：

- 使用 rustc 命令生成各阶段 IR（--emit=llvm-ir、-Z dump-mir 等），对 3-4 个 Rust 示例程序（含 Safe Rust + 少量 Unsafe）进行对比。
- 可视化简单 CFG。
- 分析编译流中的安全问题：借用检查如何防止内存漏洞、在 MIR 降低到 LLVM IR 时丢失了哪些安全信息、优化（-O0 vs -O3）对安全属性的影响。
- 针对 Unsafe 代码或简单 FFI 示例，讨论潜在风险及防御方法。

**评估与输出**：

- 生成并对比至少 3 个程序的 MIR 与 LLVM IR。
- 报告重点：Rust 编译流各阶段作用、安全语义演变、安全启示（与 C 语言对比）。

### 3. 基于大模型智能体调用工具链的编译问题分析

**目标**：理解 LLM Agent 调用编译工具链时的非确定性问题，分析 Agentic 编译中的挑战与网安风险。

**核心任务**：

- 使用 LangChain + 本地 LLM（Ollama）搭建简单 ReAct Agent，定义 4-5 个工具（rustc/clang 编译、错误解析、CSA 调用、IR 生成等）。
- 让 Agent 完成 3-4 个简单编译任务（如“编译此 Rust 代码并检查安全问题”或“优化 C 代码并生成 IR”）。
- 记录并分类 Agent 执行中出现的编译问题：无效工具调用、错误解析失败、迭代循环卡死、上下文漂移、prompt injection 等。
- 尝试构造 1-2 个 adversarial prompt，观察 Agent 是否被诱导执行危险编译命令或引入不安全选项。

**评估与输出**：

- Agent 完成至少 2 个端到端编译任务，记录 5+ 个典型问题案例。
- 报告重点：Agent 调用工具链与传统编译器的差异、常见编译问题分类、安全风险（工具链攻击）+ 缓解建议。
